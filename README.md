# MONSTER SCOUT — SALES HUNTER

The AI hunting machine for the next Monster deal.

This repository is the standalone Act 0 foundation for Monster Scout. It intentionally does not connect to Monster CRM or perform live prospecting.

Start with the [documentation router](docs/00-index.md) and [current status](docs/STATUS.md).

## Getting started

```bash
npm install
cp .env.example .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view Sales Mission Control.

See the [local-development runbook](docs/runbooks/local-development.md) for environment, Prisma, AI Gateway and verification commands.
